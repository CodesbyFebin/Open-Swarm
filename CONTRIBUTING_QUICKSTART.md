# Contributing Quick Start

## First Time Contributors

Welcome! These issues are perfect for first-time contributors:

### 🟢 Good First Issues

1. **Add security audit playbook** — Create a new playbook YAML file
2. **Parallel scout + planner** — Modify orchestrator to run nodes in parallel
3. **Better error messages** — Improve UX when Ollama is down
4. **TUI model display** — Show model names in Textual UI panels
5. **Blackboard tests** — Add unit tests for shared memory

### How to Contribute

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make changes
4. Test: `pytest tests/`
5. Submit PR with clear description

### Questions?

Open a discussion on GitHub or check docs/GETTING_STARTED.md

See [GOOD_FIRST_ISSUES.md](GOOD_FIRST_ISSUES.md) for full details.
