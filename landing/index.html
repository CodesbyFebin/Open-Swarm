Intelligent model router picks local Ollama models first, falls back to free cloud tiers automatically

⚡ Parallel agents

Scout, Planner, Coder, Critic, Synthesizer work concurrently through a shared blackboard

🔒 Zero-cost

Quick Start

git clone https://github.com/CodesbyFebin/Open-Swarm.git
cd Open-Swarm
python -m venv .venv && source .venv/bin/activate
pip install -e .
ollama pull qwen2.5-coder:3b
openswarm run "Refactor authentication to use async/await"

Three ways to use it

  • ⚡ CLI: openswarm run "your goal"
  • 🖥️ TUI: openswarm tui "your goal" — multi-panel terminal UI
  • 🌐 Dashboard: openswarm serve — http://localhost:8000/dashboard
