Why Open Swarm

🐝 Local-first routing

Intelligent model router picks local Ollama models first, falls back to free cloud tiers automatically.

⚡ Parallel agents

Scout, Planner, Coder, Critic and Synthesizer work concurrently through a shared blackboard — no wasted token round-trips.

🔒 Zero-cost, private

No API keys required, no per-token costs. Runs entirely on your machine with free-tier fallbacks.

🧭 Human-in-the-loop

Docker sandboxing and approval gates before any destructive operation — you stay in control.

📜 Declarative playbooks

YAML-defined workflows for reusable multi-agent patterns like refactors, audits, and reviews.

🧩 Open & composable

MIT-licensed Python core built on LangGraph, with MCP tool support on the roadmap.

How it works

User Goal → Router → Parallel Swarm Launch
  ├─ Scout Agent    → explore codebase
  ├─ Planner Agent  → create plan
  ├─ Coder Agent(s) → implement
  └─ Critic Agent   → verify
        ↓
  Shared Blackboard (stigmergy memory)
        ↓
  Synthesis → Human Gate → Execute

Quick Start

git clone https://github.com/CodesbyFebin/Open-Swarm.git
cd Open-Swarm
python -m venv .venv && source .venv/bin/activate
pip install -e .
ollama pull qwen2.5-coder:3b
openswarm run "Refactor authentication to use async/await"
